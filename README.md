🛠️ Descripción de Módulos y Proyectos
1. 📂 Prot_APP (Prototipos de Aplicaciones Complejas)
Animal_Planet: Prototipo enfocado en interfaz de usuario, uso de elementos multimedia (sonidos, imágenes, reproducción de audio) e interacción dinámica.

2. 📂 DB (Bases de Datos y Persistencia)
Conexion: Ejemplos prácticos de persistencia de datos (TinyDB, CloudDB o peticiones Web API / Google Sheets).

3. 📂 Registro (Autenticación y Formularios)
Clinica_salud_segura: Sistema de captura de datos para gestión clínica y formularios de registro de pacientes.

Loginbasico: Estructura básica de control de acceso mediante usuario y contraseña con validación de campos.

4. 📂 Geolocalizacion (Servicios de Ubicación)
gps: Captura de latitud, longitud y altitud mediante el componente LocationSensor.

Ubicacion: Visualización de puntos geograficos e interacción con Google Maps / MapBox.

5. 📂 Ejercicios (Fundamentos y Lógica Progresiva)
Holamundo: Introducción a eventos, botones y etiquetas.

p1_pitagoras: Aplicación matemática para calcular la hipotenusa e ingresar catetos.

p4_ruleta_rusa_1: Ejercicio interactivo basado en generadores numéricos aleatorios y condicionales.

6. 🚀 Proyectos Independientes
Calculadora2: Implementación de operaciones aritméticas estándar con interfaz de botones numéricos.

TAXI_copiar: Prototipo para solicitud o seguimiento de servicios de transporte.

Screen1: Espacio de laboratorio y testing de componentes visuales.

🚀 Cómo Importar estos Proyectos en App Inventor
Descarga el archivo .aia del proyecto que desees explorar.

Ingresa a MIT App Inventor.

Ve al menú superior: Proyectos > Importar proyecto (.aia) desde mi ordenador...

Selecciona el archivo descargado y haz clic en Aceptar.

📋 Requisitos y Herramientas
Cuenta de Google para acceder a MIT App Inventor.


Dispositivo Android con la aplicación MIT AI2 Companion instalada (o emulador de Android).

Conexión a Internet.
